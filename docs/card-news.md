# 카드뉴스 만들기

회사 한 곳의 재무제표 신호등을 인스타그램 넘김 카드(1080×1350 PNG, 7장 이하)로 만든다.
**만들기만 한다.** 어디에도 올리지 않으며, 올리는 건 운영자가 손으로 한다.

## 만드는 법

캐시만 읽는다(DART 호출 없음). 한국어 글꼴이 필요하다 — 없으면 `sudo apt-get install fonts-noto-cjk`,
또는 `.env` 에 `FIN_CHECKUP_FONT_REGULAR`·`FIN_CHECKUP_FONT_BOLD` 로 `.ttf/.otf/.ttc` 경로를 준다.

```bash
uv run python -m fin_checkup.cli site cards 005930 --year 2024 --out cards/
# cards/005930-1-cover.png … 005930-7-read.png
```

| 장 | 내용 |
|---|---|
| 1 표지 | 회사명·종목코드·사업연도·보고서 종류, 차례 |
| 2 신호등 요약 | 신호별 개수와 각 신호의 뜻, 지표 17개의 신호 목록(엔진 순서) |
| 3 수익성 · 4 안정성 · 5 현금흐름·이익의 질 · 6 성장성·효율성 | 지표마다 값·신호·경계값·계산식·쉬운 말 설명(`explain.why_color`) |
| 7 읽는 법·출처 | 색의 뜻, 출처(DART), 회사 페이지 주소(`--base-url`) |

지표가 하나도 없는 묶음의 장은 빠진다. 요약 장에서 센 지표는 모두 어느 장엔가 있다(블록을 빼지 않는다).
자리가 모자라면 글자를 줄이고(설명은 바닥글 크기 22까지), 긴 설명을 첫 문장으로 바꾸고, 그래도 넘치면 줄이 많은
설명부터 한 줄짜리(작년 값 · ⚫ 의 이유 · ⊘ 의 '대신 볼 것')로 바꾼다. **설명은 문장째 바꾸지 가운데서 자르지
않는다** — 카드에 '…' 는 없다. 신호·값·경계값·계산식과 ⊘ 의 '대신 볼 것' 은 늘 남는다. 카드 문장은 해요체 하나로
쓴다(바닥글 면책 문구만 정해진 합니다체).
그림 코드는 `src/fin_checkup/site/images/cards.py`.

## 시장 전체 카드뉴스 · 공유 카드

회사 이름 없이 시장 전체의 신호 비율만 담는다. 숫자는 `/market/` 페이지와 같은 계산이다 — 모집단은 사이트에
페이지가 생기는 회사, 비율은 `site.groups` 가 회사마다 **자기 업종 기준**으로 판정한 신호를 센 것.

```bash
uv run python -m fin_checkup.cli site cards --market --year 2025 --out cards/market/
# cards/market/market-1-cover.png … market-7-read.png  (전 상장사를 읽어 2분쯤 걸린다)
```

| 장 | 내용 |
|---|---|
| 1 표지 | 사업연도·상장사 수, 적용된 업종 기준, 차례 |
| 2~6 지표 묶음마다 한 장 | 수익성·안정성·성장성·이익의 질·효율성(엔진 순서). 묶음 안 지표 **전부** — 값이 있는 곳 수, 신호 비율 띠, 여섯 신호의 비율과 곳 수(0 곳·⚫·⊘ 포함), 일반 기준 경계값, 자기 기준을 쓰는 업종, 계산식 |
| 7 읽는 법·출처 | 비율을 읽는 법, 출처(DART), `/market/` 주소 |

장은 정해진 규칙으로 고른다 — 숫자가 눈에 띄는 지표를 골라 싣지 않는다. 사이트 빌드(`--images`)는 같은 그림을
공유 카드(1200×630)로도 만든다: `/market/` 은 `og/market.png`(엔진 순서 첫 지표), 지표 해설 `/m/<지표>/` 는
`og/m/<지표>.png`. 바닥은 출처와 짧은 면책 문구(회사 공유 카드와 같다), 카드뉴스는 모든 장에 면책 전문.

## 규칙 — 올리기 전에

- **종목을 띄우지 않는다.** 캡션·해시태그에도 추천·매수·매도·유망·저평가 같은 말을 쓰지 않는다
  (`docs/REGULATORY.md`). 카드 글자는 생성할 때 금지 표현 검사를 거치고, 걸리면 그림이 나오지 않는다.
  캡션은 사람이 쓰므로 같은 기준으로 직접 본다.
- **출처와 면책을 지우거나 자르지 않는다.** 모든 장 바닥에 출처(금융감독원 전자공시시스템 DART, 보고서)와
  면책 문구 전문이 있다. 잘라 올리거나 일부 장만 올리면 그 장에도 바닥글이 남아 있는지 확인한다.
- **"좋은 회사 N선" 같은 묶음을 만들지 않는다.** 회사를 골라 순위·목록으로 엮는 순간 측정 도구가 아니라
  종목 추천이 된다. 한 게시물에 한 회사, 고른 이유를 말하지 않는다.
- **점수로 말하지 않는다.** 신호 개수는 개수일 뿐이다 — "정상 14개라 안전" 같은 해석을 붙이지 않는다.
- 숫자는 카드에 적힌 사업연도의 것이다. 새 사업보고서가 나오면 다시 만든다.
