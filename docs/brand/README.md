# fin-checkup 브랜드

![fin-checkup 워드마크](logo-wordmark.svg)

**마크:** 귀퉁이를 접은 보고서 한 장에 세 줄 — 줄마다 신호 모양 하나와 값 막대 하나. "지표마다 측정값과 신호가 붙은
보고서", 이 도구가 하는 일 그대로입니다. 모양은 사이트 신호 표시와 같습니다: **정상 ● · 주의 ▲ · 위험 ■**.
색을 못 가려도 모양으로 읽힙니다. 막대 길이가 들쭉날쭉한 건 일부러입니다 — 차례로 줄어드는 막대는 순위표로 읽힙니다.

모양은 [`src/fin_checkup/brand.py`](../../src/fin_checkup/brand.py) 한 곳에서 정의합니다. 사이트 파비콘·머리글 마크도
여기서 나옵니다. 모양을 바꿨으면 `uv run --with fonttools python scripts/brand_assets.py` 로 이 폴더를 다시 뽑습니다
(안 뽑으면 `tests/test_brand.py` 가 실패합니다).

## 색

신호색은 사이트 신호색 그대로입니다(`site/static/site.css`, 색각 이상 시뮬레이션 검사를 통과한 값). 브랜드만의 강조색은 따로 두지 않습니다.

| 역할 | 밝은 바탕 | 어두운 바탕 |
|---|---|---|
| 정상 ● | `#11a102` | `#35b400` |
| 주의 ▲ | `#fcb51d` | `#ffcb5f` |
| 위험 ■ | `#b93e41` | `#eb6e6f` |
| 종이 | `#1b1b19` | `#3a3a36` |
| 접힌 귀퉁이 | `#55554f` | `#6e6e69` |
| 값 막대 | `#d9d9d4` | `#a6a6a0` |
| 글자 · 보조 글자 | `#1b1b19` · `#686863` | `#ececea` · `#a6a6a0` |
| 바탕 | `#ffffff` / `#f7f7f5` | `#1c1c1a` / `#141413` |

밝은 마크의 종이가 먹색인 이유: 주의 노랑(`#fcb51d`)은 흰 바탕 위에서 대비가 1.8:1 이라 잘 안 보입니다. 먹색 종이 위에선
세 신호색 모두 3:1 이상입니다(테스트가 확인).

## 글자

- 워드마크·PNG: **Noto Sans KR** (SIL OFL). 워드마크 SVG 의 글자는 윤곽선이라 글꼴 없이도 같은 모양입니다.
- 사이트: 시스템 글꼴 — `-apple-system, "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", system-ui, sans-serif`. 외부 웹 글꼴은 쓰지 않습니다.
- 이름은 늘 소문자 `fin-checkup`. 한국어 부제는 "재무제표 신호등".

## 여백과 크기

- 마크 둘레에 **값 막대 굵기의 2배(64격자의 10단위, 마크 폭의 약 ⅕)** 이상을 비웁니다. 워드마크도 같습니다.
- 마크는 16px 까지 씁니다(파비콘). 워드마크는 높이 24px 아래로 줄이지 않습니다 — 부제가 뭉개집니다. 그보다 작으면 마크만.
- 마크를 늘이거나 기울이거나, 신호 모양의 순서·색을 바꾸지 않습니다. 그림자·광택·외곽선을 더하지 않습니다.

## 말투

| 이렇게 | 이렇게 말하지 않기 |
|---|---|
| "영업이익률 13.07% — 업종 중앙값 2.00%" (값과 기준을 함께) | "실적 대박", "놓치면 손해" |
| "계산식과 경계값을 같이 보여 줍니다" | "AI 가 골라 준 종목" |
| "데이터가 없어 판정하지 않았습니다 ⚫" | 빈칸을 0 이나 좋은 말로 채우기 |
| "측정값입니다. 투자 판단은 하지 않습니다" | 추천·매수·매도·유망·저평가·TOP·"주목할" |
| 짧은 평서문, 존댓말, 숫자는 출처·연도와 함께 | 느낌표·이모지 남발, 긴급함 만들기 |

## 그리지 않는 것

- 로켓 🚀, 돈주머니 💰, 위로 꺾인 화살표, 캔들 차트, 시세 전광판 — 주식 정보·리딩 서비스처럼 보입니다(유사투자자문업의 선, [`docs/REGULATORY.md`](../REGULATORY.md)).
- 순위·메달·별점·종합 점수 게이지 — 이 도구는 종합 점수를 내지 않습니다.
- 금융감독원·DART·한국거래소 등 기관의 로고나 그 이름을 로고처럼 꾸민 것. 출처는 글자로만 적습니다.
- 청진기·심전도 같은 의료 은유 — "건강검진" 은 비유일 뿐, 진단처럼 보이게 하지 않습니다.
