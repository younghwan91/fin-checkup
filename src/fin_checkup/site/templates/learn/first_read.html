1. 숫자는 어디서 오나요

모든 숫자는 회사가 금융감독원 전자공시시스템(DART)에 낸 사업보고서에서 왔어요. 상장사는 사업연도가 끝나면 1년에 한 번 사업보고서를 내고, 그 안에 재무제표가 들어 있어요. 이 페이지의 {{ c.name }} 숫자는 {{ c.year }}년 {{ c.report_label }}의 {{ c.statement_label }}예요.

재무제표는 세 장의 표로 나뉘어요.

  • 재무상태표 — 연말 그날 회사가 가진 것(자산), 갚아야 할 것(부채), 그 차이인 주주 몫(자본).
  • 손익계산서 — 1년 동안 얼마를 팔았고(매출) 비용을 빼고 얼마가 남았는지(이익).
  • 현금흐름표 — 1년 동안 현금이 실제로 어디서 들어오고 어디로 나갔는지.

{{ c.name }}의 {{ c.year }} 사업연도 주요 숫자를 표별로 옮기면 이래요.

2. 회사 페이지를 위에서부터

맨 위 — 이름과 신호 개수

회사 이름 옆에 종목코드와 시장(KOSPI·KOSDAQ)이 있고, 그 아래 어느 해의 어떤 보고서로 계산했는지가 적혀 있어요. {{ fr.name_topic }} "{{ c.year }}년 {{ c.report_label }} · {{ c.statement_label }} · {{ c.sector_label }} 기준"이에요.

그 아래 칩은 신호마다 지표가 몇 개인지 센 것이에요. {{ fr.name_topic }} {% for chip in c.chips %}{{ mark(chip.signal.key) }}{{ chip.signal.label }} {{ chip.count }}개{% if not loop.last %}, {% endif %}{% endfor %}예요. 이 개수를 더하거나 빼서 점수를 만들지는 않아요. 지표마다 뜻이 달라서, 하나씩 읽어야 해요.

지표 17개

지표는 다섯 묶음(수익성·안정성·성장성·이익의 질·효율성)으로 나뉘어 있어요. 카드 하나에는 신호, 값, 계산식, 경계값(어느 값부터 어느 색인지), 작년 값이 함께 있어요. 색만 보지 말고 계산식과 경계값을 같이 읽으면, 왜 그 색인지 직접 확인할 수 있어요.

예를 들어 {{ fr.sample_metric_label }}({{ fr.sample_metric_easy }})의 계산식은 이래요 — {{ fr.sample_formula }}. 해설 페이지의 '실제 숫자로 계산해 보기'에 {{ c.name }}의 숫자를 그대로 넣은 계산 과정이 있어요. 지표 이름을 누르면 어느 지표든 해설로 가요.

카드 안의 띠 그림은 같은 업종 회사들의 값이 어떻게 퍼져 있는지(가운데 50%와 중앙값) 위에 이 회사가 어디쯤인지 보여 줘요. 순위가 아니라 분포예요.

몇 년 추이

최근 몇 해의 매출·이익·현금흐름 같은 숫자를 막대로 보여 줘요. 한 해 숫자만으로는 일시적인 변화인지 알 수 없어서, 흐름을 함께 봐요. 값이 없는 해는 0으로 그리지 않고 {{ mark("unknown") }}데이터 없음으로 비워 둬요.

위험 신호

자본잠식이나 몇 년 연속 영업손실처럼 재무제표만으로 확인되는 사실을 따로 모아 둔 곳이에요. 무엇을 뜻하는지는 위험 신호 해설에 있어요.

작년과 달라진 것

작년과 견줘 등급이 내려갔거나, 같은 등급 안에서도 크게 움직인 지표를 모아 둬요.

{% if fr.has_same_sector %}같은 업종 회사{% else %}같은 업종 회사{% endif %}

같은 업종의 다른 회사로 건너갈 수 있어요. 지표 값이 아니라 이름순으로 이웃한 회사들이에요. 업종 전체의 지표 분포는 업종 페이지에 있어요.

4. 이 도구가 알려 주지 못하는 것

  • 주가가 비싼지 싼지 — 재무제표만 보고, 주가나 시가총액은 보지 않아요.
  • 앞으로의 실적 — 모든 숫자는 이미 끝난 사업연도의 기록이에요.
  • 사업의 내용 — 무엇을 팔고, 경쟁 회사와 어떻게 다른지는 사업보고서 본문에 있어요.
  • 분기 사이의 변화 — 신호등은 1년에 한 번 나오는 사업보고서 기준이라, 그 사이에 생긴 일은 반영되지 않아요. 회사 페이지의 '최근 분기' 표에 그 뒤 분기보고서의 매출·이익·부채를 판정 없이 실어 둬요.
  • 공시로만 알 수 있는 일 — 감사의견, 유상증자, 전환사채, 최대주주 변경은 위험 공시 유형에서 무엇인지 볼 수 있고, 실제 공시는 DART에서 확인해요.
  • 사고팔 때 — 신호등은 측정 결과일 뿐이에요. 판단은 읽는 분의 몫이에요.
