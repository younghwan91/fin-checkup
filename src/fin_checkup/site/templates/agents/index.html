AI 에이전트에서 쓰기

AI 에이전트에게 "삼성전자 재무 진단해줘" 라고 해도 이 사이트의 측정값을 그대로 쓰게 할 수 있어요. 설치는 필요 없어요 — 에이전트가 읽을 안내(llms.txt)와 정적 파일이 사이트에 있어요.

에이전트가 지키게 한 것

  • 측정값만 전해요. 지표마다 값과 신호에 계산식·경계값을 붙여요.
  • {{ badge("unknown", "데이터 없음") }} 은 0 이 아니에요. {{ badge("not_applicable", "해당 없음") }} 은 그 업종에 맞지 않는 지표이고, 대신 볼 것을 함께 적어요.
  • 사고팔 때를 말하지 않고, 회사를 순위로 줄 세우지 않아요. 종목 추천이나 투자 판단은 하지 않습니다.
  • 답 끝에 면책 문구와 회사 페이지 링크를 붙여요.

그래도 에이전트는 틀릴 수 있어요. 숫자는 회사 페이지에서 한 번 더 확인해 주세요.

에이전트가 읽는 파일

  • llms.txt — 지킬 선, 회사 하나를 GET 두세 번으로 진단하는 법, 비교하는 법, 신호 읽는 법 (llms-full.txt 는 지표 해설 17개까지)
  • openapi.json — 정적 GET 엔드포인트와 JSON 스키마 (OpenAPI 3.1)
  • api/index.json · search-index.json — 회사 찾기 (이름·종목코드·초성)
    • {% if has_example %}
  • api/c/{{ code }}.json · c/{{ code }}/index.md — 회사 하나 (JSON · 마크다운)
    • {% endif %}

직접 불러 보기 (curl)

키도 로그인도 없어요. 정적 파일이라 호출 제한도 없어요.

# 이름으로 종목코드 찾기
curl -s {{ public_base }}api/index.json | jq '.companies[] | select(.name == "삼성전자")'

# 회사 하나 — 사실 문단과 면책 문구
curl -s {{ public_base }}api/c/{{ code }}.json | jq -r '.summary_ko, .disclaimer'

# 같은 내용을 마크다운으로
curl -s {{ public_base }}c/{{ code }}/index.md

# 어떤 파일이 있는지
curl -s {{ public_base }}openapi.json | jq '.paths | keys'
